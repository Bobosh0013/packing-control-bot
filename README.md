# Фасовка Контроль

Telegram-бот для заявок на фасовку, очереди, грузомест, фотоотчётов и синхронизации с Google Таблицей.

## Важные правила

- в одном коробе не более 23 кг товара;
- в одном кластере не более 30 грузомест;
- превышение блокируется до подтверждения администратора;
- тариф фиксируется в заявке и не меняет старые заявки;
- Google Таблица используется как отчётность и архив, а база данных — как источник правды.

## Первый запуск локально

1. Скопируйте `.env.example` в `.env`.
2. Вставьте токен только в `.env` в строку `BOT_TOKEN=`.
3. Укажите свой Telegram ID в `ADMIN_TG_IDS=`.
4. Установите зависимости: `pip install -r requirements.txt`.
5. Запустите бота: `python -m bot.main`.

Для быстрой локальной проверки используется SQLite. На BotHost будет установлен PostgreSQL.

Сейчас это безопасный стартовый модуль. Следующим шагом добавляются база данных, роли, каталог, заявки, очередь, грузоместа, фотоотчёты и Google Sheets API.

## BotHost

На BotHost загружается вся папка `packing_control_bot`. Файл `.env` создаётся на сервере отдельно и не публикуется.
